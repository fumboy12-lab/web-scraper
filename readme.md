# E-Commerce Data Extraction Engine

A production-ready Python web scraping solution designed to extract e-commerce product catalogs with precision and automated structured reporting. Built on top of `requests` and `BeautifulSoup4` for high-performance HTTP parsing, the script extracts product metadata—including titles, real-time pricing, and stock availability—and leverages `pandas` to export normalized datasets into `.csv` and formatted `.xlsx` (Excel) files.

## 🚀 Features
* **Metadata Extraction:** Scrapes product titles, prices, and stock status in real-time.
* **Dual Format Export:** Automatically processes and outputs structured datasets to both CSV and Excel formats using `pandas`.
* **Logging & Status Verification:** Features built-in HTTP status code validation and execution tracking in the terminal.

## 🛠 Tech Stack
* **Language:** Python 3.10+
* **Libraries:** `requests`, `beautifulsoup4`, `pandas`, `openpyxl`
